# Security policy

## Reporting a vulnerability

Email **support@juzpost.com** with the subject "Security" and a description of the issue, the steps to reproduce it and the affected component (this repository's plugins, the MCP server at `https://www.juzpost.com/mcp`, or the JuzPost app).

Please do not open a public issue for a vulnerability. We reply within 3 business days and keep you updated until it is fixed.

## Scope

- Plugin and extension manifests and skills in this repository.
- The hosted JuzPost MCP server and its OAuth sign-in.

This repository holds no credentials. JuzPost signs in with OAuth; no API key is stored in any manifest.
